# Sample data

`maxima_dashboard_excerpt.csv` contains 18 rows selected from the saved `Maxima 2010 Engine ON Rev.csv` capture: six rows each for CAN IDs `0x1F9`, `0x354`, and `0x625`.

The excerpt is provided to demonstrate the logger's CSV structure and the input used by the dashboard. Rows remain in their original textual form, but grouping by CAN ID means this excerpt is not in chronological order.

The full vehicle captures are intentionally excluded from the GitHub-ready package. The signal interpretations in the project are experimental observations rather than manufacturer definitions.
